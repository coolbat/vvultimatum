## Top 3 SEO moves

### 1. Weapon tier list page

Why: Google Suggest explicitly returns `vv ultimatum weapon tier list`, `quincy weapon tier list`, `hollow weapon tier list`, and `weapon reroll`. PGG has already published a dedicated page on June 12, which confirms the intent is real.

Recommended page:

- URL: `/en/guides/weapon-tier-list/`
- Title: `VV Ultimatum Weapon Tier List`
- Angles: Quincy Spirit Weapons, Shinigami Zanpakuto parts, Hollow/Arrancar weapons, weapon reroll caution, beginner-safe picks.
- Internal links: build planner, Quincy progression, Hollow progression, Shinigami progression, items/materials.

### 2. Hollow traits tier list page

Why: Google Suggest returns `best hollow traits`, `hollow traits tier list`, `best hollow build`, and `best hollow type`. PGG's page is detailed, but there is still room for a source-labeled, build-filtered page that links directly into Hollow progression and Arrancar/Vastocar choices.

Recommended page:

- URL: `/en/guides/hollow-traits-tier-list/`
- Title: `VV Ultimatum Hollow Traits Tier List`
- Angles: trait-slot count by Menos/Adjuchas/Vasto path, Hakuda/Kido/Strength/Speed/Tank filters, reset caution, Vastocar planning.
- Internal links: Hollow progression, Spirit Charms, build planner, clans tier list.

### 3. Statue Mystery / Extract locations page

Why: Google Suggest returns `how to extract from mission` and `how to reset skill tree`; SERP results include PGG, GAMES.GG, SportsRant, and multiple YouTube videos. This is a strong long-tail because the query has a clear job: get the extracts and unlock individual skill refund.

Recommended page:

- URL: `/en/guides/statue-mystery-extracts/`
- Title: `VV Ultimatum Statue Mystery Quest and Extract Locations`
- Angles: Intelligence Extract, Strength Extract, Masked Hollow Man Extract, Clint/statue route, portal reward, skill refund strategy, death/loss caution.
- Internal links: leveling guide, bosses tracker, build planning, Z-Step, items/materials.

## Secondary moves

1. Add `/en/guides/z-step/` for advanced combat mechanics. It should link from controls and skill tree content.
2. Add `/en/guides/items-materials/` as a hub, then split Hogyoku Shard, Soul Tokens, Bank Remote only if source confidence stays strong.
3. Add `/en/guides/abilities-tier-list/` only if we can keep it update-dated and avoid overclaiming exact meta after patches.
4. Add exact-match FAQ blocks to existing Shinigami/Hollow/Quincy pages for `how to meditate`, `how to get resurrection`, `how to get Shikai`, `how to get Schrift`, and `how to reroll weapon`.

## Implementation caution

- Do not create Bankai/Vollstandig pages yet unless direct current-game evidence confirms the systems. Search has video demand, but the risk of stale or speculative claims is high.
- Avoid a generic `tier-list` page that duplicates `best-race`, `clans`, and `spirit-charms`. The better SEO move is system-specific pages with internal links.
- Keep one primary keyword per URL and add source confidence dates because VV Ultimatum pages are updating daily.
